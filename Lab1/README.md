# Отчет по лабораторной работе №1: Цветовые модели

**Ссылка на проект:**
https://vanp765.github.io/Computer-Graphics-Labs/Lab1/

**Цель работы:** 
Изучить цветовые модели RGB, CMYK, HSV и разработать интерактивное веб-приложение для пересчета цветовых координат между ними в реальном времени.

**Задачи:**
1. Изучить математические основы цветовых моделей RGB, CMYK, HSV.
2. Создать графический интерфейс пользователя с ползунками, числовыми полями и палитрой.
3. Реализовать алгоритмы двустороннего преобразования: RGB ↔ CMYK, RGB ↔ HSV.
4. Обеспечить корректную синхронизацию данных между моделями без циклических пересчетов и "дрожания" интерфейса.

## Теоретическая часть
- **RGB (Red, Green, Blue)** — аддитивная цветовая модель, применяемая в экранах. Цвета получаются путем сложения излучения базовых цветов. Значения каждого канала варьируются от 0 до 255.
- **CMYK (Cyan, Magenta, Yellow, Key/Black)** — субтрактивная модель, применяемая в полиграфии. Цвета формируются вычитанием спектра из белого света. Дополнительный компонент (K) используется для получения чистого черного цвета и экономии цветной краски. Значения задаются в процентах (0–100%).
- **HSV (Hue, Saturation, Value)** — цилиндрическая модель, ориентированная на человеческое восприятие. Цвет задается тоном (H, угол 0–360°), насыщенностью (S, 0–100%) и яркостью (V, 0–100%).
- **Преобразования:** RGB и CMYK связаны линейно (через вычитание из 1 с выделением минимального значения для черного канала). Переход к HSV осуществляется через нахождение максимального и минимального каналов RGB, вычисление доминирующего цвета (тона) и разницы между экстремумами (насыщенности).

## Ход работы
1. В качестве среды разработки выбраны технологии HTML/CSS/JavaScript, что позволяет использовать нативные браузерные элементы управления (`<input type="color">`, `<input type="range">`).
2. Разработан интерфейс на базе CSS Flexbox/Grid, состоящий из трех карточек с ползунками и общей визуальной области (палитры и квадрата предпросмотра).
3. Написаны функции преобразования. Модель **RGB выбрана в качестве базовой (единый источник истины)**. При изменении CMYK или HSV, значения сначала переводятся в RGB, а затем из RGB пересчитываются остальные параметры.
4. Для предотвращения бесконечных циклов событий (Maximum call stack size exceeded) и бага с «дрожанием» ползунков из-за математического округления, в главную функцию обновления передан параметр `sourceModel`. Он запрещает скрипту перезаписывать значения той модели, с которой пользователь взаимодействует в данный момент.

## Вывод
Цель работы достигнута. Разработано программное обеспечение, демонстрирующее принципы работы и взаимосвязь базовых цветовых пространств. На практике освоены формулы перевода координат между моделями RGB, CMYK и HSV, а также решена архитектурная проблема циклического обновления связанных компонентов пользовательского интерфейса.
