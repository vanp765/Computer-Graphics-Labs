# Отчет по лабораторной работе №2: Основы обработки цифровых изображений

https://vanp765.github.io/Computer-Graphics-Labs/Lab2/

**Цель работы:** Реализовать, протестировать и сравнить алгоритмы нелинейной фильтрации на основе порядковых статистик, а также методы глобальной пороговой обработки изображений.

**Задачи:**
1. Написать программную реализацию фильтров: минимального, максимального и медианного (окно 3х3).
2. Реализовать методы глобальной бинаризации: метод Среднего и метод Оцу.
3. Подобрать тестовые изображения (наилучшие и наихудшие случаи) для демонстрации работы алгоритмов.
4. Проанализировать математические особенности и ограничения каждого метода.

## Теоретическая часть
- **Нелинейные фильтры (порядковые статистики):** Алгоритм проходит окном 3х3 по пикселям, сортирует их значения по возрастанию и выбирает элемент с заданным индексом. 
  - *Медианный (5-й элемент)* — эффективно удаляет импульсный шум («соль и перец»), сохраняя резкость границ.
  - *Минимальный (1-й) и Максимальный (9-й)* — используются для морфологической обработки (эрозия и дилатация).
  - *Особенность:* Для цветных изображений применяется маргинальный (поканальный) подход — R, G и B сортируются независимо.
- **Глобальная пороговая обработка:** Перевод изображения в градации серого с использованием весовых коэффициентов светимости (0.299 R + 0.587 G + 0.114 B) и разделение пикселей на черные (0) и белые (255) по единому порогу.
  - *Метод Среднего:* Порог равен среднему арифметическому яркости всех пикселей.
  - *Метод Оцу:* Оптимальный порог ищется путем максимизации межклассовой дисперсии между фоном и объектом на основе гистограммы.

## Ход работы и результаты тестирования
1. Программа реализована в виде веб-приложения (HTML5 Canvas + JavaScript).
2. **Тестирование фильтров:**
   - На изображении с шумом «соль и перец» *медианный фильтр* показал идеальный результат. 
   - *Минимальный и максимальный фильтры* для шумоподавления оказались непригодны (раздувают точки шума до размера окна 3х3), однако продемонстрировали пригодность для утолщения/истончения текста. 
   - Выявлен недостаток независимой поканальной обработки RGB: на резких контрастных границах могут возникать «ложные цвета», которых не было в исходном окне.
3. **Тестирование пороговой обработки:**
   - При бинаризации изображения с большой площадью белого фона *Метод Среднего* завысил порог и ошибочно выделил JPEG-артефакты фона как черный шум. *Метод Оцу* справился с задачей корректно.
   - Выявлено, что оба метода делают границы объектов «шероховатыми», так как бинаризация уничтожает переходные серые пиксели (anti-aliasing).
   - Выявлен наихудший случай для обоих методов: изображение с неравномерным освещением (градиентом теней). Глобальные методы не способны с ним справиться, для таких задач требуется локальная (адаптивная) бинаризация.

## Вывод
Задачи выполнены в полном объеме. На практике доказано, что метод Оцу значительно превосходит метод Среднего за счет независимости от соотношения площадей фона и объекта. Также подтверждена эффективность медианной фильтрации для удаления импульсных помех. Выявлены ключевые ограничения глобальных алгоритмов ЦОИ.
